load_code(name_or_slot, onerror)

Synchronously executes a code slot or local code file in the character's global CODE scope, even when called inside a function or module.

Returns: Nothing.

Repeated calls: Every call executes the file again. Repeated top-level const, let, or class declarations can fail with an Identifier has already been declared error. Repeated var initializers can reset values; initialization can also create duplicate timers or listeners.

Load shared dependencies once from the character slot, before the scripts that use them. Calling load_code from each dependent file does not skip files that have already run. Circular loading chains are not detected.

Errors: The optional onerror is a script-load error callback. Syntax or runtime errors inside a loaded browser script are reported globally; they do not call this callback or throw into the calling code, which can continue running.

Use require_code for module scope and explicit exports. It also executes on every call. See Code Slots and Files for both loading patterns and a complete module example.

Example:

Save Constants and Combat as slots that define globals. Combat can use Constants' globals without loading that slot again.

load_code("Constants"); load_code("Combat");
