is_on_cooldown(skill)

Checks the local next-skill timestamp, following shared cooldown links in G.skills.

Returns: Boolean.

Regeneration and potions: regen_hp, regen_mp, use_hp, and use_mp share one cooldown. Regeneration blocks all four for 4 seconds; an ordinary potion blocks all four for 2 seconds. These skills declare cooldown_group: "potion" in G.skills. The check follows share to the timestamp updated by the game, rather than starting a new wait based on cooldown_multiplier.

This is a local check, not a reservation. Another request can use the cooldown before yours reaches the server. A resolved use_skill Promise does not mean its cooldown has ended. See Using Skills for a regeneration example and an explanation of the shared cooldown fields.

Example:

if (!is_on_cooldown("attack")) attack(target);
