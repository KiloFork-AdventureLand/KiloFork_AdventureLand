Communicator & Chat

Open Communicator to watch your characters and chat. CHAT starts open on the server you are viewing. You can read server chat before logging in.

The conversation list puts the most recent chats first. Select a server or a private conversation to read it. Use OLDER MESSAGES to read further back, or MORE CHATS to find older conversations. On a small screen, CHATS opens the conversation list.

Sending messages

Log in, choose a character in the From field, then type your message and press Enter or SEND. For server chat, that character must be online on the selected server.

Choose NEW PM and enter the recipient's full character name to start a private chat. The sender must be online; the recipient can be on another server or offline. Replies use the same character that was part of the conversation. If that character is offline, reconnect it to reply. You can still read its messages while it is offline.

Your draft stays in its conversation while you switch chats. HIDE closes the chat window; CHAT opens it again. Watching a character, HOME IN, INVENTORY, COMMAND, and Mainframe remain available.

CODE examples

From an online character, use say for its server chat. Run this once when you want to greet the server:

await say("Hello, everyone!");

Use pm for a private message. Replace FriendName with an existing character name. The recipient can be offline. Run this separately from the greeting; chat has a cooldown.

await pm("FriendName", "Want to hunt together?");

Both functions also work in Mainframe. Mute and chat limits still apply.
