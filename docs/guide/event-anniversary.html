10 Years of Adventure

Every 30 minutes, a player is featured on each non-PvP server. Click their red KISS portrait in the INFO row to find them.

Be online when the round starts to receive an Anniversary Visit. You have five minutes to get within 80 range and use I Kiss You. Your visit is used up and you receive one slice + one Gift. No emote jar needed.

Your account always finds the same flavor. Trade for the other five.

More event details

Reachable, non-AFK players are chosen, with newer, lower-level characters favored. The featured player gets one Gift after their first visitor. Joining late gives no visit for that round; repeated kisses give no extra rewards. Replacing the featured player does not reset the five-minute timer.

Monsters can also drop slices and Gifts: separate 1-in-5,000 and 1-in-1,500 rolls, adjusted by reward share, not Luck.

Crafting needs the listed unlocked ingredients, gold, and room for the result. Stay near Mira unless you have Computer access. Mira leaves when the event ends; your items and emotes stay.

Make a Wish's jar costs one cake + 250,000 gold at Mira. The emote uses 50 MP and has a four-minute cooldown. The rare I Kiss You jar unlocks kisses outside the event. Neither gives combat bonuses.

CODE: Find and kiss

Uses server.status.anniversary and your Visit condition. If the player moves away, run it again.

async function visit_featured_player() { var round = server.status.anniversary; var ticket = character.s.anniversary_visit; if (!round || !round.active || !round.live || !ticket || ticket.ms <= 0 || ticket.round !== round.round || ticket.realm !== server.region + " " + server.id || Date.now() >= ticket.expires || Date.now() >= round.expires) { return game_log("No Anniversary Visit available right now"); } await smart_move({ map: round.map, x: round.x, y: round.y }); var current = server.status.anniversary; ticket = character.s.anniversary_visit; if (!current || !current.live || current.round !== round.round || current.id !== round.id || !ticket || ticket.ms <= 0 || Date.now() >= ticket.expires || Date.now() >= current.expires) return; var player = get_player(current.target); if (!player || distance(character, player) > 80) { return game_log("The featured player moved. Find them again."); } await use_skill("ikissyou", player); } visit_featured_player().catch(show_json);
CODE: Craft with Mira

Bring the ingredients and gold. Required quantities must be in suitable unlocked stacks.

async function craft_with_mira(recipe) { var event = server.status.anniversary; if (!event || !event.active) return game_log("Mira's workshop is closed"); await smart_move("anniversary_baker"); var result = await auto_craft(recipe); show_json(result); } // One of each slice + 100,000 gold: craft_with_mira("sixcake").catch(show_json); // Inspect other recipes before spending your cakes: // show_json(G.craft.homecomingcape); // craft_with_mira("homecomingcape").catch(show_json); // One cake + 250,000 gold; the result is a CX Jar: // craft_with_mira("makeawishjar").catch(show_json);

Inspect ingredients with show_json(G.craft). Find Mira with find_npc("anniversary_baker").

CODE: Open a Cake or Gift

Opens one item. Leave inventory room and do not move it during the exchange.
